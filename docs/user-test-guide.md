# 메추리 사용자 테스트 안내 (3일)

친구에게 그대로 보내도 되는 안내문입니다. `[ ]` 안은 보내기 전에 채우세요.

---

## 보내는 메시지

안녕! 내가 만든 메뉴 추천 앱 **메추리** 테스트를 부탁하고 싶어 🐦
"뭐 먹지?" 고민될 때 질문 몇 개에 답하면 메뉴를 골라 주는 앱이야.

- 기간: `[시작일]`부터 3일
- 하는 일: 하루에 한 번 이상, 진짜로 뭐 먹을지 고민될 때 써 보기
- 마지막 날: 설문 5문항(3분)
- 설치: `[APK 링크 또는 Expo Go QR]`

솔직한 피드백이 제일 도움 돼. 별로면 별로라고 해 줘!

---

## 설치

### Android (APK)

1. `[APK 링크]`를 휴대폰에서 연다.
2. "출처를 알 수 없는 앱" 설치를 허용한다(설정 > 보안, 기종마다 다름).
3. 설치 후 메추리를 연다.

### Expo Go로 테스트하는 경우

1. 스토어에서 **Expo Go**를 설치한다.
2. `[QR 코드 또는 exp:// 링크]`를 Expo Go로 연다.
3. 운영자와 같은 Wi-Fi에 있어야 할 수 있다.

처음 열면 위치 권한을 묻습니다. 주변 식당을 보려면 "앱 사용 중에만 허용"을 눌러 주세요. 거절해도 메뉴 추천은 됩니다.

## 3일 동안 해 볼 것

| 날 | 해 볼 것 |
| --- | --- |
| 1일차 | 홈에서 **바로 추천**을 눌러 질문에 답하고 결과를 확인. 마음에 들면 지도에서 식당까지 찾아보기 |
| 2일차 | 다른 끼니(점심/저녁)에 다시 추천받기. 마이페이지에서 못 먹는 음식을 설정하고 결과가 달라지는지 보기 |
| 3일차 | 실제로 먹을 메뉴를 메추리로 정해 보기. 끝나면 설문 작성 |

- 로그인은 안 해도 됩니다. 카카오 로그인을 하면 즐겨찾기와 기록이 저장돼요.
- 이상한 화면, 멈춤, 엉뚱한 결과가 나오면 바로 스크린샷을 보내 주세요(`[카톡/연락처]`).
- 추천 이용 기록(답변, 결과, 수락 여부)은 기기 ID로 저장돼 개선에 쓰입니다. 로그인한 상태라면 계정에도 연결돼요(탈퇴하면 함께 지워져요). 자세한 내용은 개인정보 처리방침(`[링크]`)에 있어요.

## 마지막 날 설문 (5문항)

설문 폼: `[Google Forms 링크]`

1. **추천 결과가 납득됐나요?**
   1(전혀 아니다) ~ 5(매우 그렇다). 가장 기억에 남는 결과와 이유를 적어 주세요.
2. **귀찮거나 이상했던 질문이 있었나요?**
   있었다면 어떤 질문이었고, 왜 그랬나요? (예: 너무 많았다, 뜻이 애매했다, 답하기 어려웠다)
3. **추천받은 메뉴를 실제로 먹었나요?**
   3일 동안 몇 번 먹었는지(0 / 1 / 2 / 3번 이상). 안 먹었다면 왜 안 먹었나요?
4. **"뭐 먹지?" 고민이 줄었나요?**
   1(전혀 아니다) ~ 5(매우 그렇다). 앞으로도 쓸 것 같나요? (예 / 아마도 / 아니요)
5. **하나만 바꿀 수 있다면 무엇을 바꾸고 싶나요?** (자유롭게)
