# 메추리 개인정보 처리방침 (초안)

> 초안입니다. 스토어 등록 전에 운영자 이름, 연락처, 시행일, 서버 위치(배포 후)를 채우고, 실제 코드와 다시 맞춰 보세요. 법률 검토를 대신하지 않습니다.

메추리(이하 "앱")는 이용자의 개인정보를 소중히 여기며 「개인정보 보호법」에 따라 아래와 같이 처리합니다.

- 운영자: `[이름]`
- 문의: `[이메일]`
- 시행일: `[YYYY-MM-DD]`

## 1. 수집하는 정보와 목적

| 구분 | 항목 | 목적 | 언제 |
| --- | --- | --- | --- |
| 카카오 로그인 | 카카오 회원번호, 닉네임, 이메일(동의한 경우) | 회원 식별, 즐겨찾기·기록 동기화 | 카카오로 로그인할 때 |
| 이메일 가입 | 이메일, 비밀번호(암호화 저장), 닉네임 | 회원 식별 | 가입할 때 |
| 취향 설정 | 못 먹는 음식·피하는 맛(예: 매운맛, 오이) | 추천에서 제외 | 마이페이지에서 저장할 때 |
| 이용 기록 | 즐겨찾기한 메뉴, 먹은 메뉴 기록 | 마이페이지 표시, 추천 개인화 | 이용자가 저장할 때 |
| 추천 이용 통계 | 앱 설치별 무작위 기기 ID, 로그인한 경우 회원번호, 추천 세션 ID, 질문 답변, 결과 메뉴, 수락/거절 여부, 시각 | 추천 품질 개선(결과 수락률 등 지표) | 추천을 이용할 때(로그인하지 않아도) |
| 같이 정하기 | 방에서 쓰는 닉네임, 질문 답변, 못 먹는 음식(로그인한 경우 계정 설정에서 복사), 로그인한 경우 회원번호 | 여러 사람의 답을 모아 함께 먹을 메뉴 정하기 | 방을 만들거나 참가할 때, 방에서 질문에 답할 때 |
| 위치 | 현재 위치(위도·경도) | 주변 식당 검색 | 메뉴 추천·월드컵·지도 화면을 열 때, 권한을 허용한 경우만 |

- 위치는 식당 검색 요청에만 쓰이며 회원 정보나 이용 통계에 저장하지 않습니다. 서버는 같은 검색을 반복하지 않도록 대략적인 좌표와 검색어를 메모리에 최대 10분간 보관한 뒤 지웁니다.
- 기기 ID는 휴대폰 고유번호(IMEI, 광고 ID 등)가 아니라 앱이 처음 실행될 때 만드는 무작위 값입니다.
- 앱은 백그라운드에서 위치를 수집하지 않습니다.
- 만 14세 미만 아동의 가입을 받지 않습니다.

## 2. 보관 기간

- 회원 정보, 취향 설정, 즐겨찾기, 기록: 탈퇴할 때까지. 탈퇴하면 즉시, 영구히 지웁니다.
- 추천 이용 통계: 수집일로부터 1년. 로그인한 상태로 쌓인 통계는 탈퇴할 때 함께 지웁니다. 로그인 없이 기기 ID로만 쌓인 통계는 사람을 알아볼 수 없어 탈퇴와 관계없이 1년 뒤 지웁니다.
- 같이 정하기 방 기록: 방은 만든 뒤 2시간이 지나면 닫힙니다. 닫힌 방의 닉네임과 답변은 30일 뒤 지웁니다. 탈퇴하면 그 전이라도 방 기록에서 회원번호와 복사된 못 먹는 음식을 즉시 지웁니다. 닉네임과 답변은 같은 방 사람들의 결과에 필요해서 방 기록이 지워질 때까지 남습니다.
- 로그인 처리용 일회성 코드: 발급 후 1분 이내 사용 또는 만료 시 삭제.
- 법령에 따라 보관해야 하는 경우 그 기간 동안 보관합니다.

## 3. 제3자 제공과 처리 위탁

앱은 이용자의 개인정보를 판매하거나 제3자에게 제공하지 않습니다. 기능 제공을 위해 아래 서비스를 이용합니다.

| 서비스 | 보내는 정보 | 목적 |
| --- | --- | --- |
| 카카오 (카카오 로그인) | 로그인 요청 | 회원 인증 |
| 카카오 (카카오 로컬 API) | 검색어(메뉴 이름), 좌표 | 주변 식당 검색 |
| `[호스팅 업체, 예: Render]` | 서버·데이터베이스 운영 | 앱 서버 운영 |

## 4. 이용자의 권리

이용자는 언제든지 다음을 요청할 수 있습니다.

- 내 정보 열람, 수정
- 즐겨찾기·기록 삭제(마이페이지에서 직접)
- 회원 탈퇴와 전체 정보 삭제: 앱에서 **마이페이지 > 회원 탈퇴**를 누르고 확인하면 즉시 처리됩니다. 앱을 쓸 수 없으면 `[이메일]`로 요청해 주세요(7일 이내 처리).
- 카카오 계정과 앱의 연결 끊기: 탈퇴해도 카카오 쪽 연결은 자동으로 끊기지 않습니다. 카카오톡 설정 > 카카오계정 > 연결된 서비스 관리에서 끊을 수 있습니다.
- 위치 권한 철회(휴대폰 설정 > 앱 > 메추리 > 위치)

## 5. 안전성 확보 조치

- 비밀번호는 bcrypt로 암호화해 저장합니다.
- 서버와의 통신은 HTTPS로 암호화합니다.
- 로그인 토큰은 기기에만 저장하며 로그아웃하거나 탈퇴하면 지웁니다.
- 로그인하지 않고 쓴 즐겨찾기·기록은 기기에만 저장되며, 로그인하면 계정으로 옮겨집니다.
